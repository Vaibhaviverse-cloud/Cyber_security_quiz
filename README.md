# 🛡️Cyber Security Awareness Quiz

An interactive, dark-themed cyber security awareness platform built for students of NGO School (Classes 9–12) to help them recognize phishing attacks, create strong passwords, identify online scams and secure their everyday applications through engaging, hands-on activities.

Built as part of my **Social Internship**, aimed at spreading digital safety awareness among school students.

---

## Features

- **Single-page application** — no reloads, smooth section transitions
- **Cyber Safety Rules briefing** — 10 must-know rules before starting
- **Level 1: Phishing Awareness** — embedded phishing video + a validated quiz that only lets you proceed once every answer is correct
- **Level 2: Password Security Lab** — live password strength checker (length, uppercase, lowercase, number, special character). Students must successfully create five strong passwords before unlocking the next level.
- **Level 3: Scam or Not?** — 20 real-world scam scenarios including phishing, QR code fraud, OTP scams, fake bank alerts, reward scams, WhatsApp fraud, and suspicious SMS messages
- **Scenario-based decision making activities** — instead of plain MCQs, students judge realistic messages/calls and get instant feedback with explanations
- **Level 4: App Security Checklist** — accordion-style checklists for securing Google, WhatsApp, Instagram & Snapchat accounts
- **Progress persistence** — uses `localStorage` so a student's progress isn't lost on refresh
- **Back navigation** — move between levels freely to review earlier sections
- **Completion certificate screen** — confetti animation and official cybercrime helpline/portal info (1930 / cybercrime.gov.in)

---

## 🛠️ Tech Stack

Built **from scratch** with:

- **HTML5**
- **CSS3** (no Bootstrap, no Tailwind)
- **Vanilla JavaScript** (no React, no jQuery, no frameworks/libraries)
- Also learn new Animations type flicker by using AI 

No build tools, no dependencies, no npm install required — just open `files` in a browser and it works.

> The JS is shipped in a obfuscated form (`script.js`) to keep quiz answers from being trivially visible in "View Source."

##  Running It Locally

No installation needed:

1. Download/clone this repository
2. Open `index.html` in any modern browser

That's it — works fully offline once loaded (except the embedded YouTube video and Google Fonts, which need internet).
